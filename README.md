# MyExamQuiz

Тренажёр для подготовки к экзаменам Microsoft Azure (WPF, .NET 8).

## Вопросы хранятся в JSON

Все наборы вопросов вынесены из кода в папку [`Data/`](Data). При сборке файлы
копируются в выходной каталог (`bin/.../Data`), откуда их читает приложение —
пересобирать проект после правки вопросов не нужно, достаточно обновить JSON
рядом с `MyExamQuiz.exe`.

### Языковые версии — один экзамен, несколько файлов

Имя файла с вопросами устроено так: `<база>.<язык>.json`. Файлы с одной и той же
базой — это один и тот же набор на разных языках:

```
az-900.rus.json        ┐ экзамен «AZ-900»
az-900.eng.json        ┘
az-900-set2.rus.json   ┐ экзамен «AZ-900 · набор 2»
az-900-set2.eng.json   ┘
```

В списке экзаменов такая пара показывается **одной** записью, а язык выбирается
отдельным списком рядом. В режиме обучения язык переключается прямо во время
теста — кнопкой в шапке или клавишей `L`; номер вопроса, выбранный ответ, счёт
и разбор при этом сохраняются.

Разделителем служит именно суффикс `.<язык>.`, а не совпадение начала имени:
`az-900` является началом `az-900-set2`, и по «общему префиксу» все четыре файла
слились бы в один набор.

### `Data/exams.json` — список экзаменов

```json
[
  {
    "code": "AZ-900",
    "name": "Azure Fundamentals",
    "description": "Основы облачных вычислений и Microsoft Azure",
    "questionsBase": "az-900",
    "defaultLanguage": "rus"
  },
  {
    "code": "AZ-104",
    "name": "Azure Administrator",
    "description": "Администрирование и управление ресурсами Azure",
    "questionsFile": "az-104.json"
  }
]
```

| Поле              | Описание                                                            |
|-------------------|---------------------------------------------------------------------|
| `code`            | Код экзамена, показывается в списке                                  |
| `name`            | Название экзамена                                                    |
| `description`     | Подпись под списком экзаменов                                        |
| `questionsBase`   | Общая часть имени языковых файлов — будут найдены все `<база>.<язык>.json` |
| `questionsFile`   | Один файл вопросов — для набора без языковых версий                  |
| `defaultLanguage` | Код языка, выбранный по умолчанию (необязательно)                    |

Нужно указать либо `questionsBase`, либо `questionsFile`. Коды языков `rus` и
`eng` показываются как «Русский» и «English»; незнакомый код выводится как есть.

### Файл вопросов — массив объектов

```json
[
  {
    "id": 1,
    "uid": "5NYV8",
    "text": "Which cloud deployment model ...?",
    "options": [
      "A) Public cloud",
      "B) Hybrid cloud",
      "C) Community cloud",
      "D) Private cloud"
    ],
    "correctAnswer": "D",
    "correctAnswerText": "D) Private cloud",
    "difficulty": 1
  }
]
```

| Поле                | Описание                                                        |
|---------------------|------------------------------------------------------------------|
| `id`                | Номер вопроса; по нему сохраняются закладки                       |
| `uid`               | Постоянный код вопроса — связывает языковые версии (см. ниже)     |
| `text`              | Текст вопроса                                                     |
| `options`           | Варианты ответа, каждый начинается с буквы и `)`                  |
| `correctAnswer`     | Буква правильного варианта (`A`…`D`)                              |
| `correctAnswerText` | Полный текст правильного варианта — должен совпадать с `options`  |
| `difficulty`        | Сложность 1–5, используется фильтром в главном окне               |

#### `uid` — как связаны русская и английская версии

Одинаковые вопросы в парных файлах помечены одним и тем же кодом `uid`: пять
символов из алфавита `23456789ABCDEFGHJKMNPQRSTVWXYZ` — без `0`/`O`, `1`/`I`/`L`
и `U`, чтобы код нельзя было прочитать неоднозначно. Код постоянен: он не зависит
от порядка вопросов в файле и не меняется при перенумерации, поэтому именно он, а
не `id`, служит ключом сопоставления.

```
az-900.rus.json:  { "id": 1, "uid": "5NYV8", "text": "Какая модель развёртывания..." }
az-900.eng.json:  { "id": 1, "uid": "5NYV8", "text": "Which of the following..." }
```

Поле необязательное: если `uid` нет, версии сопоставляются по `id` — так старые
файлы продолжают работать. При загрузке приложение проверяет, что у связанных
версий совпадают `correctAnswer` и число вариантов; расхождение — ошибка данных,
о которой приложение сообщает и не даёт начать тест, потому что иначе смена языка
меняла бы правильный ответ.

Новому вопросу нужен свой, ещё не занятый `uid` — он должен быть уникален в
пределах набора.

### Пояснения (необязательные поля)

Три поля ниже можно не указывать вовсе, указать частично или оставить пустыми —
приложение работает и без них, просто не показывает соответствующий блок.

```json
{
  "explanation": "Почему верен правильный ответ.",
  "whyOthersWrong": "Кратко: почему неверны все остальные варианты.",
  "whyWrong": {
    "B": "Почему неверен вариант B.",
    "C": "Почему неверен вариант C.",
    "D": "Почему неверен вариант D."
  }
}
```

| Поле             | Описание                                                                  |
|------------------|---------------------------------------------------------------------------|
| `explanation`    | Развёрнутый разбор на 3–5 предложений: что это за концепция, почему она подходит под условие задачи, где проходит граница применимости. Хранится один раз и используется в обоих сценариях |
| `whyOthersWrong` | Краткая сводка одним предложением по остальным вариантам                    |
| `whyWrong`       | Буква варианта → почему именно он неверен, одно предложение. Ключа правильного ответа быть не должно |

`explanation` намеренно не пересказывает текст правильного варианта — он объясняет
механику, поэтому в существующих наборах занимает 68–106 слов.

Что показывается в режиме обучения:

* **Верный ответ** — `explanation`, затем `whyOthersWrong`.
* **Неверный ответ** — `whyWrong` для выбранной буквы, затем `explanation`.
  Сводка `whyOthersWrong` здесь не выводится: точная причина по выбранному
  варианту уже показана, и сводка была бы повтором.

Текст «почему верен правильный ответ» не дублируется: он лежит только в
`explanation`, а в `whyWrong` попадают лишь неверные варианты.
Если ключ в `whyWrong` совпадает с буквой правильного ответа, приложение его
игнорирует — ошибка в данных не превратится в противоречивую подсказку.

### Готовые наборы

| Файл                       | Экзамен            | Язык    | Вопросов | ID          | Пояснения |
|----------------------------|--------------------|---------|----------|-------------|-----------|
| `az-900.rus.json`          | AZ-900, основной   | Русский | 240      | 1–240       | есть      |
| `az-900.eng.json`          | AZ-900, основной   | English | 240      | 1–240       | есть      |
| `az-900-set2.rus.json`     | AZ-900, набор 2    | Русский | 240      | 1001–1240   | есть      |
| `az-900-set2.eng.json`     | AZ-900, набор 2    | English | 240      | 1001–1240   | есть      |
| `az-104.json`              | AZ-104             | English | 30       | 1–30        | нет       |

Первые четыре файла образуют две пары, то есть **два** экзамена в списке.

Второй набор AZ-900 сгенерирован как альтернативный: он покрывает те же домены
экзамена, но не повторяет ни одного вопроса из основного набора. Его ID начинаются
с 1001, чтобы закладки не пересекались с другими наборами.

#### Русские версии

Файлы `*.rus.json` — это полноценная русская редакция обоих наборов AZ-900, а не
машинный перевод: формулировки написаны так, как если бы вопрос сразу готовили
по-русски. При этом сохранены структура и смысл оригинала — те же `id`,
`correctAnswer`, порядок и буквы вариантов, тот же набор ключей в `whyWrong`.
Названия продуктов и служб Azure (`Azure Key Vault`, `Microsoft Entra ID`,
`Conditional Access`) не переводятся, а переводимые понятия даются по-русски с
английским термином в скобках, например «Эластичность (elasticity)».

Английские оригиналы остаются на месте: они лежат рядом под именами
`*.eng.json` и образуют с русскими файлами пару, поэтому в списке экзаменов
каждый набор по-прежнему одна запись. Закладка ставится на вопрос целиком и
видна в обеих языковых версиях.

### Как добавить новый экзамен

1. Положите файлы вопросов в `Data/`:
   * с языковыми версиями — `az-204.rus.json` и `az-204.eng.json`;
   * без них — просто `az-204.json`.
2. Допишите запись в `Data/exams.json`: `"questionsBase": "az-204"` для пары
   либо `"questionsFile": "az-204.json"` для одиночного файла.
3. Запустите приложение — экзамен появится в выпадающем списке, а языки
   подтянутся из имён файлов автоматически.

Чтобы добавить ещё один язык к готовому набору, достаточно положить рядом файл
`az-900.deu.json` с теми же `uid` — правки `exams.json` не потребуется.

Если JSON повреждён или файл не найден, приложение покажет сообщение с путём и
причиной ошибки, а кнопка старта останется недоступной.
